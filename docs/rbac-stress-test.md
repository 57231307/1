# RBAC 压力测试与性能监控

## 概述

本文档描述 RBAC（基于角色的访问控制）系统的压力测试要求和性能监控指标。

## 压力测试场景

### 1. 并发权限检查

- **目标**：验证权限检查在高并发下的性能
- **并发数**：100、500、1000
- **持续时间**：5 分钟
- **成功标准**：P99 延迟 < 100ms，错误率 < 0.1%

### 2. 角色分配风暴

- **目标**：验证批量角色分配的性能
- **操作**：同时为 1000 个用户分配角色
- **成功标准**：全部完成，无死锁

### 3. 权限缓存失效

- **目标**：验证缓存失效后的性能恢复
- **操作**：清空权限缓存后立即发起大量请求
- **成功标准**：P99 延迟 < 500ms，5 秒内恢复

## 性能监控指标

| 指标 | 阈值 | 告警条件 |
|------|------|----------|
| 权限检查延迟 P99 | < 100ms | > 200ms |
| 权限检查 QPS | > 1000 | < 500 |
| 缓存命中率 | > 95% | < 90% |
| 数据库连接池使用率 | < 80% | > 90% |

## 监控命令

```bash
# 查看权限检查延迟
curl http://localhost:9090/api/v1/query?query=rate(permission_check_duration_seconds_sum[5m])

# 查看缓存命中率
curl http://localhost:9090/api/v1/query?query=permission_cache_hit_rate
```
