# 离线报表 ETL 设计文档

## 概述

本文档描述离线报表 ETL（Extract, Transform, Load）的设计方案，用于定期生成和分发报表数据。

## 架构设计

### 数据流

```
数据源 → 提取 → 转换 → 加载 → 报表存储 → 分发
```

### 组件

1. **数据提取器**：从数据库提取原始数据
2. **数据转换器**：清洗、聚合、计算指标
3. **数据加载器**：写入报表表或文件
4. **调度器**：定时触发 ETL 任务
5. **分发器**：邮件/消息推送报表

## 报表类型

### 日报

| 报表名称 | 生成时间 | 数据范围 | 接收人 |
|----------|----------|----------|--------|
| 销售日报 | 每日 08:00 | 前一日 | 销售经理 |
| 生产日报 | 每日 08:00 | 前一日 | 生产经理 |
| 库存日报 | 每日 08:00 | 当前 | 仓库主管 |

### 周报

| 报表名称 | 生成时间 | 数据范围 | 接收人 |
|----------|----------|----------|--------|
| 销售周报 | 每周一 09:00 | 上周 | 销售总监 |
| 质量周报 | 每周一 09:00 | 上周 | 质量经理 |

### 月报

| 报表名称 | 生成时间 | 数据范围 | 接收人 |
|----------|----------|----------|--------|
| 财务月报 | 每月 1 日 10:00 | 上月 | 财务总监 |
| 供应商评估月报 | 每月 5 日 10:00 | 上月 | 采购经理 |

## 实现建议

1. 使用 SeaORM 查询数据
2. 使用 serde 序列化为 JSON/Excel
3. 使用 tokio-cron-scheduler 定时调度
4. 使用 email-service 发送报表
5. 报表文件存储在 `/data/reports/` 目录
