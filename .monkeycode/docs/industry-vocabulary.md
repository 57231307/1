# 面料行业术语中英对照表

## 基础术语

| 中文 | 英文 | 说明 |
|------|------|------|
| 面料 | Fabric | 纺织品总称 |
| 坯布 | Greige Fabric | 未染色的布料 |
| 色卡 | Color Card | 颜色标准卡 |
| 色号 | Color No. | 颜色编号 |
| 缸号 | Dye Lot No. | 染色批次编号 |
| 匹号 | Piece No. | 布料单元编号 |

## 染整工艺

| 中文 | 英文 | 说明 |
|------|------|------|
| 染色 | Dyeing | 给面料上色 |
| 印花 | Printing | 在面料上印制图案 |
| 后整理 | Finishing | 染色后的处理工序 |
| 定型 | Setting | 固定面料尺寸和形态 |
| 预缩 | Pre-shrinking | 减少面料缩水率 |

## 质量指标

| 中文 | 英文 | 说明 |
|------|------|------|
| 色牢度 | Color Fastness | 颜色持久性 |
| 克重 | Gram Weight | 面料重量（g/m²） |
| 幅宽 | Width | 面料宽度 |
| 缩水率 | Shrinkage Rate | 洗涤后收缩比例 |
| 起毛起球 | Pilling | 面料表面起球现象 |
